# java-calculator-precourse
# 구현할 기능 목록

## 입력/출력
- 입력 문구 : '덧셈할 문자열을 입력해 주세요.'
- 입력 : `camp.nextstep.edu.missionutils.Console.readLine()` 사용
- 출력 : '결과 : 합계'

## 기본 계산
- 빈 문자열 `""` → `0` 반환
- 기본 구분자 : 쉼표 `,`, 콜론 `:`
- 구분자로 분리된 양의 정수를 모두 더해 합 반환

## 커스텀 구분자
- 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용
- 예: `"//;\n1;2;3"` → `6`

## 예외 처리 (IllegalArgumentException)
- 사용자가 잘못된 값 입력 시 예외 발생
- 예외 발생 시 애플리케이션 종료
